# CHRISTMAS / PARTICLE ATELIER

一个使用 NumPy + Pygame 实现的实时 3D 粒子圣诞树。树冠使用约 30,000 个细至单像素的粒子构成，粒子保留 XYZ 世界坐标，通过 yaw / pitch 相机变换和透视投影绘制到窗口。

## 运行环境

- Python 3.10 或更新版本
- NumPy 1.24 或更新版本
- Pygame 2.5 或更新版本（推荐 Pygame 2.6.x）

## 安装

在项目文件夹打开终端：

```bash
python -m pip install -r requirements_christmas_tree_3d_pro.txt
```

也可以直接安装：

```bash
python -m pip install numpy pygame
```

## 启动

```bash
python christmas_tree_3d_pro.py
```

Windows 用户也可以双击 `run_windows.bat`（前提是 Python 已加入 PATH，并且依赖已安装）。

## 实现拆解

### 1. 真正的 3D 粒子场景

树体粒子、灯带、装饰球、彩灯、雪花和烟花都保留 XYZ 坐标。每帧先执行相机 yaw / pitch 变换，再使用透视投影映射到屏幕坐标。树体不是单纯的屏幕三角形。

树冠默认由约 30,000 个细粒子组成，叶片粒子以单像素点绘制，而不是大圆点。通过 NumPy `surfarray` 批量写入像素层，避免逐粒子调用绘图函数，兼顾密度与运行速度。

### 2. 鼠标粒子吸附

鼠标位置通过反投影映射到一个面向相机的 3D 平面。按住左键时，为附近粒子施加随距离衰减的吸引力；粒子的速度和位置由弹簧力、阻尼和 NumPy 向量运算更新。

### 3. 树体解构与重组

每个树体粒子都有一组树形目标坐标和一组星云目标坐标。按下空格后切换目标，粒子通过弹簧动力学平滑飞散或归位。

### 4. 烟花

右键或按 F 发射烟花。烟花包含上升阶段、尾迹、球形爆炸粒子、重力和寿命衰减；程序也会定时自动发射少量烟花。

### 5. Bloom 泛光

将发光对象绘制到低分辨率透明光照缓冲区，再使用 smoothscale 放大并以加法混合叠加到主画面，近似模拟 Bloom。

### 6. 景深

根据粒子到相机的深度与焦平面距离计算离焦量。离焦粒子会在低分辨率层中形成更大的柔和光斑；滚轮或方括号可以改变焦平面。

## 性能调整

如果设备帧率不理想，可以在源文件顶部调整：

- `WIDTH, HEIGHT`：降低窗口分辨率，例如 960 × 700。
- `TREE_PARTICLE_COUNT = 30000`：调整树冠粒子数量；性能较弱的设备可降至 12000–18000，性能较好的设备可尝试 36000。
- 树冠粒子采用单像素绘制；如需要略粗的颗粒质感，可在 `pixels3d` 批量写入方式之外另加少量两像素高光点，不建议把主体粒子恢复成大圆点。
- `BLOOM_SCALE = 4`：改成 5 或 6 可降低光照缓冲区开销（数值越大，缓冲区越小）。
- `snow_count = 235`：减少雪花数量。
- `FPS = 60`：可以调整到 45 或 30。

## 技术说明与限制

- 这是基于 Pygame 2D 绘图表面实现的自定义 3D 粒子渲染器，不依赖 OpenGL。三维性来自 XYZ 坐标、相机变换和透视投影。
- Bloom 是低分辨率光照缓冲 + 平滑放大 + 加法混合的实时近似。
- 景深是基于粒子深度的实时散景近似，不是物理正确的镜头模拟。
- 为保持纯 Pygame 依赖，未使用 GPU shader；若后续想做真正的体积光、屏幕空间 Bloom、景深散焦核和更大规模粒子，建议迁移到 ModernGL / OpenGL 或网页 Three.js。
